Expense Tracker

Overview

Expense Tracker is a Python application that helps users manage their finances by recording income and expenses, calculating balances, and organizing spending data.

Features

- Add income records
- Add expense records
- Categorize expenses
- Calculate total expenses
- Display current balance
- Store data using JSON files

Technologies Used

- Python
- JSON

Skills Demonstrated

- File handling
- Data management
- Functions
- User input processing
- Financial record tracking
- Problem-solving
